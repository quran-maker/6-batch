## GitHub + Netlify তে প্রকাশ
1. github.com এ নতুন repository খুলুন → **uploading an existing file**।
2. এই ফোল্ডারের **ভেতরের সব ফাইল** একসাথে টেনে দিন (`node_modules` ফোল্ডার বাদে)। এখানে কোনো সাব-ফোল্ডার নেই, সব ফাইল সমান স্তরে।
   দরকারি ফাইল: `index.html, admin.html, app.js, admin.js, data.js, style.css, favicon.svg, api.mjs, netlify.toml, package.json, package-lock.json`
3. **Commit changes** চাপুন।
4. app.netlify.com → **Add new site → Import an existing project → GitHub** → repository বাছাই → **Deploy**। (বিল্ড সেটিংস `netlify.toml` থেকে নিজেই নেবে, কিছু বদলাতে হবে না।)
5. ডেপ্লয় শেষে `/admin.html` এ গিয়ে লগইন করুন।

ডাটাবেস (Netlify Blobs) আলাদা করে চালু করতে হয় না — নিজে থেকেই কাজ করে।
